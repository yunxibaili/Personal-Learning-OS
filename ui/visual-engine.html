Design System v1 · ADR-025

Visual Engine：代码是主角
步进是检查，不是播放

V1 是受控的 Python 教学示例执行可视化器，不是通用代码可视化器。 只执行随代码发布的 6 个示例，用户任意代码不执行。 交互范式采用 IDE 调试器语义（Step Over / Into / Out / Continue）而非播放器—— 没有播放三角，没有拖拽进度条；轨迹全量已录，所以「后退」天然成立。

实况原型

数据为项目 tracer 真实产出（POST /api/v1/trace/run 的 TraceRun v1， 由 server/app/core/tracer/ 跑 6 个示例生成后内联），非手造演示数据。 面板聚焦后可用键盘步进。

—
example.py 无轨迹
输出 · stdout
（无输出）

键盘：↓ 单步进入 · → 单步跳过 · ↑ 单步跳出 · Space 继续 · ← 上一步 · R 重新开始（需先点击面板使其聚焦）

为什么不用播放器

2026-09-01 所有者裁定，记录于 ADR-025 §3.2。

播放器隐喻（播放三角 + 可拖拽进度条）被否决。 播放器的隐含语义是「这是一段视频，看完就好」；而算法可视化的真实用途是 检查程序在某一步的状态。调试器语义让代码保持主角地位，图形是同步的解释器而非装饰。 轨迹一次性全量返回，所以「后退」不需要播放器也能实现——它是调试器的「回到上一步」，不是倒带。
借鉴对象取什么不取什么
VS Code Python Debug inline values（行尾变量值）、CALL STACK 帧列表、Step Over / Into / Out 三态语义 断点、调试控制台、变量树折叠——教学场景不需要
Python Tutor 当前行高亮 + 帧/变量面板分离、步进可前后导航、模块级帧也进栈 Heap 对象图（ADR §4.3 已取消 heap 字段，值内联在 locals）、滑块播放器
birdseye 行执行次数热力——静态全貌通道，与动态的「当前行」分离 表达式级取值（需 AST 改写，超出 V1 sys.settrace 能力）

编码通道预算

沿用 ADR-023 判据「一个维度 = 一个通道」。橙色是全站唯一的强调色， 只服务注意力指针与进度，不用于静态分类（变量类型、数据类型等）。

维度允许通道禁止

组件规范

五件。类名与 ui/archive/visual-engine-tsx-2026-09-01/visual-engine.css 一致，回灌 React 时可直抄。

组件职责要点
VisualEngine 组合壳：CodePane + Renderer + DebugToolbar 三区布局 左代码 / 右图形 6:4（视线横向移动幅度小）。步进状态是面板局部 state，不进 ui store（业务数据一律来自 API）
CodePane 代码主体：gutter 行号 + 执行热力 + 当前行橙底 + 行尾 inline values 着色是零依赖纯函数（6 类记号，用既有令牌，不引新色相）。跨行三引号 docstring 由行间传递状态处理
DebugToolbar 步进控制：⟲ 重新开始 / ← 上一步 / 单步进入 / 跳过 / 跳出 / 继续 无播放三角、无进度条。快捷键避开 F5/F10/F11（浏览器会抢走），改用方向键 + 空格 + R
ArrayView 数组条形化（排序 / 二分） 高亮的是「本步相对上一步真的变了的下标」——纯数据比较，不猜指针（ADR §3.4 禁止算法语义推断）
FrameStackView / GeneralView 调用栈（递归）/ 通用帧 + 变量（V1 fallback） 栈顶在上，深度 = y 偏移。模板由清单 template 字段路由，前端不做任何语义分析

状态与空态

ADR-025 §4.4：四类非 completed 状态一律返回 HTTP 200——用户代码的问题是业务结果， 不是 API 调用失败。UI 错误态不是空态：超时/超限时仍回放已录得的部分轨迹， 用户能看到程序卡在哪一步，这本身就是诊断信息。

执行超时

timeout · 超过 MAX_RUNTIME=10s。顶部黄底提示条说明原因， 下方照常回放已录得的部分轨迹。

status=timeout · HTTP 200
轨迹超限

trace_limit · 超 MAX_TRACE_EVENTS=5000 或 MAX_RECURSION_DEPTH=100。尾部标注「以下为已录得的部分轨迹」。

status=trace_limit · HTTP 200
执行出错

error · SYNTAX / IMPORT_DENIED / RUNTIME。 提示条转红底，展示 error.type 与 error.message。

status=error · HTTP 200
执行完成

completed。真正的 HTTP 4xx/5xx 只用于调用方错误 （未知 example_id → 404，mode:"vta" → 400，并发超限 → 429）。

status=completed · HTTP 200
  • 空态：无轨迹时代码 pane 显示源码 + 「无轨迹」；图形区显示「暂无可视化数据」，容器定高不塌陷（CLS 铁律）。
  • 无匹配示例的 Concept：不渲染 Visualize 按钮——不是灰置，是不出现（ADR §3.3）。
  • 值展示：Python 语义，None / True / False，不是 JS 字面量。未知对象 → <ClassName object>（绝不调用用户 repr()）。

步进语义

纯函数，栈深 = frames.length（ADR §4.2，frames[0] 为当前帧）。

动作键语义
单步进入 into↓前进一个事件，包括进入被调用函数内部
单步跳过 over→在本层执行完这一行：跳到后面第一个栈深 ≤ 当前的事件
单步跳出 out↑执行到当前函数返回：跳到后面第一个栈深 < 当前的事件
继续 continueSpace直接到末步
上一步 back←回到上一个事件（轨迹全量已录，无需重放）
重新开始 restartR回到起点
  • 越界输入一律 clamp：末步再按单步进入仍停在末步，不会溢出成 undefined。
  • 按钮的 disabled 由 canStep() 判定（目标下标 === 当前下标即不可用），调用方不必自己做边界判断。
