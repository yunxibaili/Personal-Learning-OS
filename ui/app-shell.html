极限与连续

#数学 #微积分 已复习 3 次 掌握度 72%

定义

函数 f(x) 在 x = a 处的极限是 L，当且仅当对任意 ε > 0，存在 δ > 0，使得当 0 < |x − a| < δ 时，|f(x) − L| < ε。

核心直觉：我们关心的是 x 趋近于 a 时 f(x) 趋近什么，而不是 f(a) 本身的值。这就是 极限 与 函数值 的关键分离。

ε-δ 语言

ε-δ 定义是分析学的基石。它把"无限趋近"翻译成有限的、可验证的不等式游戏。

∀ε > 0, ∃δ > 0: 0 < |x − a| < δ ⇒ |f(x) − L| < ε

连续性

f 在 a 处连续当且仅当同时满足：

  • f(a) 有定义
  • lim(x→a) f(x) 存在
  • lim(x→a) f(x) = f(a)
联系：极限 → 连续 → 可导 → 可积。前者是后者的必要条件。
