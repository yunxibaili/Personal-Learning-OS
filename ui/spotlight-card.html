M-SPOTLIGHT · 空状态聚光引导

聚光是引导，不是装饰

鼠标经过时，一团很淡的暖光从指针位置溢出，把视线推向唯一的出口。 它只在空状态里成立——当界面没有内容可读、且用户只有一条路可走时， 聚光是功能；一旦界面有了要读的内容，聚光就变成了干扰阅读的装饰，那正是 ADR-013 §2.7 要禁的东西。本页把这条边界写死：下面三张卡可交互，把鼠标移上去看效果。

交互演示

三张卡都处于「无内容 + 单一出口」状态。聚光仅在指针悬停时出现，移开即散。

允许 / 禁止

右边那张卡刻意做了反例：内容一旦出现，聚光就该撤掉。

✓ 允许 · 空状态引导（唯一出口）

  • 知识星系空态：还没有笔记
  • 首次引导 / Onboarding：建 vault、选文件夹
  • 空列表：暂无反链、暂无待复习、暂无记忆点
  • 加载失败兜底：只有「重试」一个出口时

✕ 禁止 · 任何有内容可读的界面

  • 笔记列表卡、复习卡、检索结果卡
  • 右栏已有内容的面板（反链、掌握度、批注）
  • 常亮聚光（非 hover 触发）
  • 描边式聚光、玻璃态、霓虹发光
  • 对外物料 / 落地页（另议，不属本例外）
反例 · 内容卡

今日复习

  • 线性代数 · 矩阵乘法
  • 数据结构 · 二叉树的遍历
  • 概率论 · 条件概率
反例判据：这张卡有三行要读的列表。聚光从字底下滑过时， 读者的注意力被从内容拉到指针上 —— 这直接违背「内容优先」， 也把橙从「注意力指针」降级成了「会动的背景」。因此禁用。

规范

三条门禁 + 实现约束。任一条不满足就回到普通卡片（无聚光）。

三条门禁（缺一不可）

条件要求判据
空状态 界面无内容列表、无正文、无数据图表 渲染分支是 empty / onboarding / error，不是 loaded
单一出口 该界面只有一个主 CTA，没有并列动作 卡内 button 数量为 1（关闭 / 辅助链接不计）
可撤销 仅 hover 触发；触摸设备与 prefers-reduced-motion 下完全不启用 整段包在 @media (hover:hover) and (prefers-reduced-motion:no-preference) 内

实现约束

项取值理由
聚光强度 rgba(255,107,53,.13) 中心，38% 处衰减到 .04，62% 全透明 叠加在白底上不产生可见色块；不承载文字，因此不受对比度约束
半径 普通卡 320px / 大号卡 460px 覆盖卡片主体即可，不外溢到相邻卡片
过渡 opacity var(--dur) var(--ease-out)（250ms） ADR-013 §2.6 微交互 150–250ms 上限
指针跟随 事件委托 + 单 rAF + 30fps 节流；只写 --mx/--my 两个自定义属性 性能契约：单 rAF、30fps 节流、循环内不重建 DOM
CTA 对比度 --brand-deep 底 + 白字 = 4.13:1（AA）；hover 转 --brand-text 5.18:1 --brand 配白字仅 2.84:1，不达标；故按钮不用 --brand
禁止 gradient 描边、conic 流光、常亮光晕、box-shadow 动画 ADR-013 §2.7 / §2.10 完整有效，本例外只豁免「hover 时的背景光晕」
与 ADR-013 的关系：本组件是 §2.7「禁 gradient」的唯一例外， 依据 docs/adr/ADR-013-frontend-design-system.md §2.13（2026-09-02 所有者裁定）。 例外范围严格限定为「空状态引导的背景光晕」，不扩及渐变背景、按钮渐变、描边渐变或任何常亮效果。
