M9 · Visual Engine · 组件演示

组件跑起来的样子

这一页是 M9 视觉引擎六个组件的可交互演示，不是规范说明。 组件样式直接引用 ./visual-engine/visual-engine.css， 数据来自后端 tracer 的真实 TraceRun（6 个示例、348 步轨迹）。 交互范式是 IDE 调试器，不是播放器——没有播放三角，没有进度条。

VisualEngine · 组合组件

CodePane（左 6）+ Renderer / stdout（右 4）+ DebugToolbar。 切换示例、点按钮或用键盘步进；焦点在组件内时快捷键生效。

键盘： ↓ 单步进入 · → 单步跳过 · ↑ 单步跳出 · 空格 继续到结束 · ← 上一步 · R 重新开始。 刻意避开 F5/F10/F11——浏览器会抢走。
输出 · stdout（累计到当前步）

            

          

        


        

      

    

  







  

    
子组件分解

    

      每个组件单独定格在真实轨迹的某一步上，便于逐个核对编码通道。数据同样来自下面的 TraceRun。
    


    

      
      

        

          CodePaneui/visual-engine/CodePane.tsx
          当前执行行 = 橙底；调用者行 = 墨蓝底；行执行次数 = gutter 竖条透明度；变化的变量 = 行内橙描边
        

        

      


      
      

        

          ArrayViewui/visual-engine/ArrayView.tsx
          元素值 = 条高（长度通道）；本步变化的下标 = 橙描边，不改填充色
        

        

      


      
      

        

          FrameStackViewui/visual-engine/FrameStackView.tsx
          递归深度 = y 偏移（位置通道）；栈顶帧 = 橙边框；变化的局部变量 = 橙底
        

        

      


      
      

        

          GeneralViewui/visual-engine/GeneralView.tsx
          兜底渲染器：不做算法推断，把当前帧所有序列变量平铺为值列表
        

        

      


      
      

        

          DebugToolbarui/visual-engine/DebugToolbar.tsx
          六动作调试语义；disabled 由 canStep() 判定；右侧为步号与栈深
        

        

      

    

  







  

    
编码通道预算

    
一个维度只占一个通道。橙 = 注意力指针，不用于静态分类（ADR-025 §3.6）。

    

      
        
维度通道为什么

      
      
        
当前执行行--brand-soft 底 + 左边框橙唯一通道，不同时改字号/加边框/加动画

        
调用者所在行--ink-soft 底 + 墨蓝左边框中性色，不与「当前行」抢橙

        
行执行次数gutter 竖条 opacity静态全貌的唯一通道，越多次越实

        
变量变化橙描边（不改填充）填充已被「当前行」占用，避免双编码

        
递归深度卡片 margin-left 递增位置编码，不用颜色深浅（深浅不可数）

        
数组元素值柱高长度通道，不叠色相

        
栈顶帧橙边框与「当前行」同一语义族：注意力指针
