本原型保留三栏 IA，把中栏从单一「长文编辑器」升级为「主笔记概览视图」（截图 1 形态）： 顶部 stats · chip 与卡片双向锚 · 卡片网格。 真正的「写正文」从顶栏或卡片 → 右栏「大纲」点击 → 进入编辑器模式（此处留待回灌实现）。

区域原来现在

右上角 Mini Star（88px 星球 + 卫星） 取消。2026-09-02 裁定：不再有「卫星 = 笔记」这套映射，笔记区不出现卫星系统；点阵地球只作主页 Hero 的固定动画（见 dot-earth.html）。

规范要点

  • 概览与编辑分离。 默认进来是概览（一眼掌握这篇笔记），要写正文再点 chip/卡片进入 editor（不在此页呈现，避免页面切换扰乱思路）。
  • 概览不放动图。 右上角曾放 88px Mini Star，2026-09-02 移除：卫星系统与「笔记」解绑后它失去语义，且任何持续运动的图形放在标题旁都会抢正文的注意力（ADR-013 §2.10）。笔记区的视觉层级为：标题 → stats → chip → 卡片，全部静态。
  • 橙只给选中。 卡选中态 = brand-soft 底 + 左缘 2px brand 描边（左缘而不全描边，避免「被强调框死」）。
  • 形状即语义。 ProgressRing 用纯 SVG + stroke-dashoffset，不用渐变与光晕；chip 用 pill 形状，不靠颜色区分。
  • 三栏塌缩链。 ≤1080 收起右栏 → ≤780 收起左栏 → ≤560 全屏单栏；移动端 chip 仍在，stats 自动等宽。
