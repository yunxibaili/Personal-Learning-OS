贝叶斯定理的直觉

大多数人第一次接触 贝叶斯定理 时，会被公式吓住。但它说的其实是一件很朴素的事：看到新证据之后，你该把信念往哪儿挪。

从一句话开始

定理的形式只有一行：

P(A|B) = P(B|A) · P(A) / P(B)

读法比公式重要：P(A) 是你原本的看法（先验），P(B|A) 是假设成立时看到这个证据的可能性（似然），P(A|B) 则是看完证据后你该有的看法（后验）。

先验不是偏见，它是你在看到这批证据之前已经付出的所有学习成本。

为什么容易搞反

最常见的错误是把 P(A|B) 和 P(B|A) 当成一回事。疾病检测的阳性预测问题就是典型：检测准确率 99%，不代表阳性者 99% 患病——还得看基础发病率，也就是先验 条件概率复习。

  • 先验越低，越需要强证据才能翻转结论
  • 似然比决定证据的「话语权」大小
  • 反复用新证据更新后验，就是学习的数学形式

一个小例子

假设某病基础发病率 0.1%，检测灵敏度与特异度都是 99%。那么一次阳性之后，真实患病概率仍只有约 9%。直觉会强烈抗议这个数字，但算一遍就服气了：

p_disease   = 0.001
p_pos_given = 0.99        # 灵敏度
p_pos_healthy = 0.01      # 假阳率

p_pos = p_pos_given * p_disease + p_pos_healthy * (1 - p_disease)
p_disease_given_pos = p_pos_given * p_disease / p_pos
# → 0.0902

这也解释了为什么系统要记录每一次 掌握度 的更新历史：先验是逐步积累出来的，一次测验不该推翻此前全部证据。

为什么正则化能防止过拟合

过拟合的本质是模型记住了训练集中的噪声。当参数量远大于样本量时，模型几乎可以插值任意训练集1，此时训练误差趋近于零，但泛化误差反而上升。

正则化通过在损失函数中加入惩罚项来限制模型复杂度。以 L2 为例，它在目标函数后加上 λ‖w‖²2，使得权重倾向于取较小的值，从而降低模型对单个样本的敏感度。

从贝叶斯角度看，L2 正则等价于对权重施加高斯先验。这一点建立了频率学派与贝叶斯学派的桥梁3：最大化后验概率，等价于最小化「损失 + 正则项」。

实践中 λ 的选择依赖交叉验证。较大的 λ 会导致欠拟合4，需要在偏差与方差之间权衡。

4 条批注 · 1 条需修改
1逻辑AI
「当参数量远大于样本量时…」

插值成立还要求模型有足够表达能力。参数量大是必要非充分条件，这里说成因果了。

2错误AI
「λ‖w‖²」

漏了系数。标准形式是 (λ/2)‖w‖²，加 1/2 是为了求导后消掉系数。

3肯定AI
「建立了…桥梁」

这个连接抓得准。你在《先验与后验》里推导过同一个式子，可以引过来互相印证。

4建议我
「较大的 λ 会导致欠拟合」

λ 的选择还要考虑特征量纲——没标准化的特征会被惩罚得更狠，这句得补上。
