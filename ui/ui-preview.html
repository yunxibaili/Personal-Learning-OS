贝叶斯定理的直觉

● 已保存·1,284 字·更新于 14:32

大多数人第一次接触 贝叶斯定理 时，会被公式吓住。但它说的其实是一件很朴素的事：看到新证据之后，你该把信念往哪儿挪。

从一句话开始

定理的形式只有一行：

P(A|B) = P(B|A) · P(A) / P(B)

读法比公式重要：P(A) 是你原本的看法（先验），P(B|A) 是假设成立时看到这个证据的可能性（似然）。

导师批注 · 双向 hover 联动

Wikilink · HLUnder · Annotation · AIRibbon

原文不动，右 gutter 显示批注；双向 hover 联动（原文 → 批注 / 批注 → 原文）。AI / 用户来源区分。

大多数人第一次接触 贝叶斯定理 时，会被公式吓住。

定理的形式只有一行：

P(A|B) = P(B|A) · P(A) / P(B)

读法比公式重要：P(A) 是你原本的看法（先验），P(B|A) 是似然。

导师 AI 错误
把 P(A|B) 与 P(B|A) 互换了。两者的区别正是后文的「似然 vs 后验」。
我 赞同
补一句「先验不是偏见」—— 它是你在看到这批证据前已经付出的学习成本。
导师 AI 建议
可以用疾病检测的 0.1% 发病率 + 99% 灵敏度做个小例子，让直觉跟上算式。
四类批注用色：错(red) / 建(orange) / 肯(green) / 逻(墨蓝)。批注不修改原文，避免破坏笔记作为事实源。
