M-NOTE-TREE v2 · 星系层级

层级是轨道，不是目录

主/副笔记是严格单父关系（子笔记 frontmatter 写 parent: "[[父标题]]"， 事实源在 Markdown）。左栏把它渲染成星系：主笔记 = 星球，副笔记 = 沿轨道入轨的卫星。 v2 相对 v1 只改了「怎么动」——数据规则、编码通道、键盘语义全部不变： 展开从 display:none 硬跳变改为轨道生长，卫星依次入轨，星球点展开成轨道环。

Bento 卫星网格

网格体系取自归档稿 archive/legacy-gallery-html-2026-09-01/bento-dashboard.html—— 只取「尺寸 = 重要性」的网格原则与 tile 跨列/跨行， 不取它的独立仪表盘定位（裁决 A 已删）与 MiMo 风视觉。

尺寸分档（三档上限，超过三种比例会破坏节奏）

档位占位判定承载内容
主卫2x23 列 × 2 行链数 ≥ 6标题 + 4 行摘要 + 链数 + 掌握度环
中卫2x13 列 × 1 行链数 3–5标题 + 2 行摘要 + 链数
小卫1x12 列 × 1 行链数 < 3标题 + 链数（无摘要）

响应式（4→2 断点，规划在先）

视口列数
≥ 1000px--bento-cols: 6，三档尺寸全部启用
620–1000px--bento-cols: 4，主卫降为 2 列 × 2 行
< 620px--bento-cols: 2，全部 tile 退化为 span 2 × 1 行（单列堆叠）

为什么能用（与归档理由不冲突）

bento 被归档的原因是「作为一个独立的学习仪表盘页面」——裁决 A 已决定 学习数据分散到该出现处（复习徽章、右栏掌握度），不设独立仪表盘。 本页取用的是纯布局层的网格体系，承载的是「选中星球的卫星」， 属于层级视图自身的展开内容，不引入任何新的数据域， 也不新建一个页面级入口。归档稿本身保持只读（archive/ 只进不出）。

规范

组件只做渲染与交互；层级来自关系解析层，本组件不做任何推断。

数据规则（未变 · 来自 ADR-024 裁决链）

规则约定
事实源子笔记 frontmatter parent: "[[父标题]]"；Markdown 是唯一权威，DB links(relation=parent) 只是可重建的派生索引
单父一个笔记最多一个 parent；vault 可形成多棵树（forest）。底层允许 parent 链，V1 界面只渲染一层（星球/卫星）
权威优先显式 parent > 拓扑推断；树数据统一来自 resolve_hierarchy()，本组件不自行推断
orphan（无效父级）parent 指向不存在的笔记 → 进「未挂载」组，保留原值 + 警告标记，绝不自动删除 parent
展开状态纯视图状态：可存 localStorage，不进 vault、不进 SQLite
卫星上限≤ 16（性能契约，与 Galaxy 一致）；超出折叠为「显示全部 N 颗」

交互规则（未变）

操作行为
点击行打开笔记并置为 active；若该行处于收起的父级内，先展开祖先链
点击 › 箭头仅展开/收起，不切换 active——两个命中区分离，消除误触
无卫星的星球箭头占位但不可点；展开后显示「空轨道」+ 新建副笔记 CTA（不用聚光渐变，用虚线圈）
过滤框输入标题含关键词的行保留；命中行祖先自动展开；计数与分组标签隐藏；零命中显示「没有匹配的笔记」
↑ ↓在可见行间移动 active（循环）
→ / ←展开 / 收起当前星球；卫星行按 ← 回到星球行

动效预算（本次新增）

动效时长 / 缓动约束
轨道生长--dur / --ease-spring只动 grid-template-rows；不测高度、不逐帧
卫星入轨--dur / --ease-springdelay = --i × 45ms；卫星 > 8 颗时 delay 上限 200ms，避免尾部过久
星球展开--dur / --ease-spring只过渡 width/height/padding/border-width（可合成外的属性，限单节点）
数字滚动--dur-slow / --ease-out单 rAF + 30fps 节流；reduced-motion 直接落终值
tile hover--dur-fast / --ease-out仅 translateY(-2px) + 边框色；禁 box-shadow 动画
全部：prefers-reduced-motion 下统一降到 0.01ms；离屏（IntersectionObserver + visibilitychange）不触发；contain: layout paint 已加在 rail 与 sys 上

业界对照

来源做法本项目取舍
Sidebar Tree Navigation（2026-03）grid-template-rows: 0fr→1fr 做展开动画，配合 inert 同时管视觉与无障碍树采纳核心手法——这是目前唯一无需测高度、纯 CSS 的树展开方案
widgets_extended · SyncedSliverTree插入生长 / 移除收缩 / 跨层级滑移；isFirst/isLast 让连接线绘制变简单部分采纳：只取「入场 stagger」；不做 drag-reorder（vault 是事实源，拖动会引入写路径）
Bento Grid（Apple / Notion / Linear）12 列基础网格，tile 尺寸编码重要性，uniform gap，2–3 种尺寸上限，dense 补位采纳网格原则（本项目用 6 列）；弃独立仪表盘定位
Notion 侧栏整行点击打开页面；箭头独立区域只管展开沿用——误触最低的范式
Obsidian · Nested Pages过滤时命中分支自动展开 + 跟随 active 展开祖先沿用
VS Code 资源管理器→← 展开/收起、↑↓ 移动的树键盘语义沿用——与 M9 视觉引擎方向键上下文不同，不冲突
本项目 Galaxy（星系）主笔记 = 星球、副笔记 = 卫星；层级从 /graph 边拓扑推断对齐心智模型：左栏用同一套「星球/卫星」词汇，只是从画布落回列表

与 note-workspace.html 的关系

本页是组件规范页：只定义左栏树本体与右侧卫星系统。回灌项目时替换 NoteListView 的平铺列表区，栏宽/过滤框/rail-head 沿用工作区现值，不改三栏布局。 右侧 Bento 卫星系统属于可选增强——若右栏已被掌握度占用，可只回灌左栏轨道树， 卫星网格降级为"展开后内嵌 2 列"（--sat-cols: 2，本页已同时实现）。
