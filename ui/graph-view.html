ADR-023 冲突已裁决（2026-08-29）。 原文档有两处对 Graph 与 mastery 的说法不一致，无法同时成立：
  • 视觉编码条款写「Concept = 圆形 + mastery 环」。
  • 数据流边界表 Graph 列却标注 mastery「❌（仅 tooltip）」， 且「禁止」条款写「mastery 视觉投射」。
裁决：取视觉编码条款——保留 mastery 环，并明确它是 Graph 中 mastery 的唯一视觉出口， 禁止尺寸 / 填充色 / 排序 / 动画等其他投射。ADR-023 已同步修订：「禁止」条款补上唯一例外， 新增「编码通道预算」横切约束。本次未放宽任何冻结边界。
