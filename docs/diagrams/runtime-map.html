2 · Frozen Contracts (read-only constraints)
ADR-001 · Markdown Truth
  • vault/*.md = source of truth for content
  • SQLite = rebuildable cache/index
  • startup: full-scan + content_hash verification
ADR-008 · Entity Model
  • concepts = first-class citizens
  • links = unified polymorphic edges
  • concept ≠ note (entity ≠ document)
ADR-014 · AI Boundary
  • LLM reads context → generates text
  • LLM NEVER writes DB / mastery / events
  • All state changes → learning_event
Learning Model · Truth Hierarchy
  • learning_events = immutable fact (append-only)
  • concept_mastery = derived state (replayable)
  • review_queue = projection (rebuildable)

9 · Data Truth Flow
Markdown → SQLite → Learning State → AI → Universe
vault/*.md → parser → concepts + links + notes → learning_events → concept_mastery → review_queue
→ Tutor Context → LLM → Response     concepts + links + mastery → Universe
Data Rebuildability
  • SQLite index ← rebuildable from vault/*.md (startup full-scan)
  • concept_mastery ← rebuildable from learning_events (event replay)
  • review_queue ← rebuildable from concept_mastery + SM-2 algorithm
  • Universe projection ← rebuildable from concepts + links + mastery
10 · Frozen Boundary — What AI Agent Cannot Touch
DO NOT MODIFY:
• learning_events schema (append-only)
• concept_mastery formula (0.35K+0.30P+0.20R+0.15T)
• sm2_schedule algorithm
• build_prompt() contract
• LLMProvider protocol
• vault/*.md truth guarantee
